# Project Guide

React + Vite + Tailwind CSS application.

## Project Structure

- `src/main.tsx` - Application entry point
- `src/App.tsx` - Main application component
- `src/index.css` - Global styles and Tailwind CSS import
- `index.html` - HTML document shell
- `package.json` - Dependencies and project scripts
- `vite.config.ts` - Vite, React, Tailwind, and path-alias configuration

## Development

Install dependencies with `pnpm install`, start the development server with `pnpm dev`, and create a production build with `pnpm build`.

## Styling

The project uses Tailwind CSS v4 through `@tailwindcss/vite`. Global styles and theme customization belong in `src/index.css`.
